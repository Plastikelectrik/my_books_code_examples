# Code examples — JavaScript for Absolute Beginners

Every numbered example from the book, organized by chapter. Example 01 → `example_01.*`.

## How to use

- Install Node.js (any current LTS version) and a code editor such as VS Code.
- Console examples: run them with `node example_NN.js` from inside this folder. The `package.json` here makes Node.js treat files as modules, which the examples with `import` or `await` (such as the guessing game in Chapter 10) need.
- Web examples (`.html`, `.css` and the DOM chapters): open the HTML file in a browser and use the developer tools console.
- The `projects/` folder contains the complete coffee quiz (Chapter 25) and habit tracker (Chapter 28). The quiz opens directly in a browser; the habit tracker uses modules, so start a local server in its folder (`npx serve .`) and open the address it prints.
