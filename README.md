# Code Examples — Robotics & AI Essentials

Code examples for the books by **Oscar Gomez** in the *Robotics & AI Essentials* series.
Each book has its own folder, organized by chapter and appendix. Every file is named
after its number in the book (Example 01 → `example_01.*`).

| Folder | Book | Examples |
|---|---|---|
| [Build-Smart-Robots](Build-Smart-Robots/) | *Build Smart Robots* | Python, Arduino, MicroPython, ROS 2 |
| [Robotics-and-AI-Explained](Robotics-and-AI-Explained/) | *Robotics & AI Explained* | Python |
| [Raspberry-Pi-Projects-for-the-AI-Age](Raspberry-Pi-Projects-for-the-AI-Age/) | *Raspberry Pi Projects for the AI Age* | Python, shell, configuration files |
| [Nodejs-for-DevOps-Engineers](Nodejs-for-DevOps-Engineers/) | *Node.js for DevOps Engineers* | JavaScript, TypeScript, JSON, YAML |
| [JavaScript-for-Absolute-Beginners](JavaScript-for-Absolute-Beginners/) | *JavaScript for Absolute Beginners* | JavaScript, HTML, CSS, JSON |
| [Rust-for-Beginners](Rust-for-Beginners/) | *Rust for Beginners* | Rust, TOML configuration files |
| [Mastering-REA-STUDIO](Mastering-REA-STUDIO/) | *Mastering REA STUDIO* | Python, shell, PowerShell, C, C#, Kotlin, Java, JavaScript, HTML, ImHex patterns, configuration files |

Each folder contains a `README.md` with setup instructions and the full list of examples.

## Safety

The examples are provided as is, for learning. Some examples control real hardware
(motors, power supplies, GPIO pins, cameras, microphones) or network services.
Read the safety and legal notes in the book before running them.
